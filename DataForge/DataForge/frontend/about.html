About DataForge

Explore the website's components, tools, and features.

Welcome to DataForge

DataForge provides a workspace for preparing datasets, generating synthetic records, evaluating data quality, examining privacy-risk indicators, and exporting results. This guide explains the purpose of each page and its available components.

1. Home

The Home page introduces the main functions available on the website. It helps users navigate to the dataset workspace, generation tools, privacy analysis, evaluation results, and reports.

2. Dashboard

The Dashboard provides a quick overview of the current data-processing workflow. It can present dataset information, generation status, recent activity, and available evaluation summaries, depending on the data currently stored by the application.

  • Dataset overview: Displays available information about the dataset.
  • Generation status: Helps users identify the current workflow stage.
  • Metric summaries: Provides a quick view of available evaluation results.

3. Dataset Workspace

The Dataset Workspace is used to prepare the data that will be used for synthetic generation.

  • CSV Upload: Allows users to select a supported CSV file.
  • Sample Datasets: Provides example data for exploring the workflow.
  • Dataset Profiling: Examines columns, data types, missing values, and basic statistical information.
  • Schema-Based Data: Supports creating demonstration data from a defined column structure, where available.

4. Generate Data

The Generate Data page creates synthetic records using patterns and statistical characteristics from the selected dataset.

  • Generation Settings: Configures the available options for generating records.
  • Numerical Sampling: Generates numerical values using statistical sampling.
  • Categorical Sampling: Uses observed category frequencies to generate categorical values.
  • Constraints: Applies supported numeric limits or other configured conditions.
  • Candidate Iteration: Allows users to generate and compare alternative candidates when supported.
  • Data Preview: Helps users inspect the generated records before export.

5. Privacy Lab

The Privacy Lab presents checks that help identify possible privacy risks in synthetic data. It may examine record overlap and other supported heuristic indicators.

  • Risk Indicators: Summarizes the privacy checks performed by the application.
  • Overlap Checks: Identifies potential similarities between source and generated records when implemented.
  • Risk Interpretation: Helps users understand which results may need further review.

These checks are not a guarantee of anonymity and do not replace formal privacy techniques such as differential privacy.

6. Evaluation

The Evaluation page helps users assess how closely the synthetic dataset represents selected characteristics of the source dataset.

  • Statistical Comparison: Compares supported numerical and categorical distributions.
  • Missing-Value Analysis: Compares missing-value patterns where applicable.
  • Visualizations: Uses charts to make comparisons easier to understand.
  • Evaluation Metrics: Presents the quality measurements calculated by the application.

Evaluation results describe the metrics implemented in the website; they should not be interpreted as proof that every property of the original dataset has been preserved.

7. Reports

The Reports page organizes available generation and evaluation information so users can review the results of their workflow.

  • Evaluation Summary: Presents available quality results.
  • Privacy Summary: Shows the privacy-check outcomes that were recorded.
  • Synthetic Data Passport: Documents available dataset details, generation settings, and evaluation information.
  • Export Options: Provides supported report or dataset downloads.

8. Navigation Bar

The navigation bar provides links to Home, Dashboard, Dataset Workspace, Generate Data, Privacy Lab, Evaluation, Reports, and About. It allows users to move between the website's main sections.

9. Reset Button

The Reset button provides the website's configured reset action. Depending on its implementation, it may clear the current workflow state or return the interface to its initial state. Review the confirmation message, if displayed, before proceeding.

10. Notifications and Validation

Status messages help users understand whether an operation succeeded, whether input data is valid, or whether an error occurred. Validation messages can help identify unsupported files, missing inputs, or incorrect settings.

Typical Website Workflow

01 Prepare Upload a CSV or select available sample data.
02 Generate Configure the options and create synthetic records.
03 Evaluate Review quality metrics and visual comparisons.
04 Review & Export Inspect privacy indicators and download available results.

Important Usage Note

Synthetic data is generated data, not automatically anonymous data. Review the quality metrics and privacy indicators before using or sharing generated records. Avoid uploading sensitive information unless the environment is appropriate and authorized for that data.
